# Learning-C

Small C programs I wrote while learning the language. Each file is a standalone program that does one simple thing, like a calculator, a GCD finder or an odd/even checker.

## How to use

You need a C compiler (gcc works fine). Pick any file and compile it:

    gcc Calculator.c -o Calculator
    ./Calculator

On Windows you can skip compiling and just run the `.exe` that sits next to each `.c` file.
